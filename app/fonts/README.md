# Plein

Official family: https://www.fontshare.com/fonts/plein

Official download used on October 23, 2026: https://api.fontshare.com/v2/fonts/download/plein

`Plein-Variable.woff2` is the original, unmodified 30,888-byte WOFF2 from `Plein_Complete/Fonts/WEB/fonts` in the official archive. The supplied CSS declares a continuous `wght` range of 300–900. The static styles are Light 300, Regular 400, Medium 500, Bold 700 and Black 900, plus italics. The website uses only the normal variable file, mainly at 400, 500 and 600. Weight 600 is real variable interpolation, not synthetic bold. Emphasis is upright, with no synthesized italic.

The included `FFL.txt` is ITF Free Font License 2.0, August 17, 2026. Section 01 explicitly permits personal/commercial use and self-hosting on the licensee's websites/apps. Section 02 prohibits modifying the font, including subsetting and format conversion, and restricts standalone redistribution and supplying the font to external parties. We use the supplied WOFF2 without modification. Retain the license and do not publish these files as a font download or public font repository; external contractors should obtain their own copy from Fontshare.

Next.js serves this one file locally with swap display and an adjusted Arial fallback. CSS disables font synthesis globally. There are no third-party font requests, italic files, unused static weights, or legacy Public Sans/Newsreader assets.
